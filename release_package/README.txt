AI Players 本地更新包
====================

此包将主模组和独立配置助手更新到 0.2.10。

安装：
1. 完全退出游戏。
2. 双击 install_update.cmd。
3. 等待两个 xcopy 操作完成后关闭窗口。
4. 启动游戏，打开 AI Players 配置，重新输入 API Key，然后点击 Apply。
5. 重启游戏世界使配置生效。

更新不会修改世界存档、modoverrides.lua 或 API 密钥配置。旧配置里若已保存成星号，无法从旧值恢复，必须在新版本配置界面重新输入。

包含目录：
- ai_players：服务器模组
- ai_players_config：独立的客户端配置助手
